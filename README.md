### Featured Tools

**[rcdebug](https://github.com/roulettegun/rcdebug)** · [![PyPI](https://badgen.net/pypi/v/rcdebug?color=black)](https://pypi.org/project/rcdebug/) ![Python](https://badgen.net/pypi/python/rcdebug?color=black)
Command-line debugger and security scanner for Roblox games on macOS (`pip install rcdebug`). Built on the Python 3 standard library with zero external dependencies. It watches live client logs while you play, audits `.rbxlx` place files and Luau scripts for unsafe remotes or receipt bugs, and searches a 120,000-entry flaw catalog in under 10ms.

**[LUA-Deobfuscater](https://github.com/roulettegun/LUA-Deobfuscater)** · [![Last commit](https://badgen.net/github/last-commit/roulettegun/LUA-Deobfuscater?color=black)](https://github.com/roulettegun/LUA-Deobfuscater) ![Static](https://badgen.net/badge/analysis/static-only/black)
Python static unpacker for obfuscated Lua 5.1 and Luau scripts. Reconstructs readable code from Prometheus VMs, rolling-XOR string tables, seeded PRNG ciphers, and nested `loadstring` wrappers directly on disk without running untrusted code.
